# Portrait directory

Add optional character portraits here as WebP or PNG files. The expected paths come from the `image` field generated in `src/data.js`. The app checks for WebP first and then PNG.

Examples:

- `seigaku/ryoma-echizen.webp`
- `seigaku/ryoma-echizen.png`
- `hyoutei/keigo-atobe.webp`
- `rikkai/seiichi-yukimura.webp`

Portraits should ideally use a 4:5 or square crop. Missing files automatically use the matching team-colored monogram treatment.
